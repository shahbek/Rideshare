# Architectural styles — catalog, data mapping, and how to add one

Ordinary buildings are generated by `scripts/styles.py`. A style is **data** (palette, roof, trims,
window module, rhythm) plus a few **extras** (small generators for porticos, turrets, timbering...).
Every style reuses the same machinery: repaired footprint → walls → roof solver → sweeps →
instanced modules. So adding a style rarely needs new geometry code.

Reference renders: `assets/gallery_styles.png` (all styles), `assets/gallery_awkward.png`
(awkward footprints through the styled pipeline).

## 2. Choosing a style from map data

Use explicit tags when present. Otherwise use region defaults, then building type, size, and a
per-building hash so streets aren't uniform.

**OSM / Overture tags:**

| Tag | Use |
|---|---|
| `building:architecture` = `victorian`, `tudor`, `art_deco`, `modern`, `neoclassicism`, `colonial`, `mediterranean`, `gothic`, `romanesque`, `ottoman`, `mughal`... | direct style / landmark variant |
| `building` = `church`, `cathedral`, `chapel` / `mosque` / `temple`, `shrine` | landmark type (`church`, `mosque`, `pagoda`) |
| `amenity=place_of_worship` + `religion` (+ `denomination=orthodox`) | church vs mosque, `orthodox` variant |
| `roof:shape` = `gabled`, `hipped`, `flat`, `mansard`, `dome`, `pyramidal`, `onion` | override `roof.kind` (pyramidal → hip on square; dome/onion → landmark dome) |
| `roof:colour`, `building:colour`, `building:material` (`brick`, `stone`, `plaster`, `glass`) | palette override / wall material → style family |
| `height`, `building:levels`, `roof:levels`, `min_height` | H, levels, setbacks (`building:part`s with heights → tower tiers) |
| `building` = `house`, `detached`, `terrace`, `apartments`, `commercial`, `office`, `retail` | low-rise style family |

**Region defaults** (weighted lists, picked by hash):

| Region | Houses / low-rise | Mid-rise / commercial | Landmarks |
|---|---|---|---|
| NYC / US north-east | `brownstone`, `colonial`, `victorian` | `art_deco`, `fenn_office` | towers `art_deco`, `classic`, `modern_glass`; churches `gothic` |
| California, Florida, US south-west | `spanish`, `fenn_house` | `art_deco` (Miami), `modernist` | `spanish` mission churches → `romanesque` palette swap |
| UK | `tudor`, `victorian` | `fenn_rowhouse` | `gothic` |
| Netherlands, Belgium | `dutch_canal` | `fenn_rowhouse` | `gothic` |
| Greece mainland / islands | `greek_revival` / `cycladic` | `cycladic`, `modernist` | `byzantine`, `orthodox` |
| Spain, Latin America | `spanish` | `spanish`, `modernist` | `romanesque` |
| Tanzania, Kenya coast, Zanzibar | `dar_house`, `swahili_house`, `informal` (density) | `dar_apartment`, tower `dar_glass` | `swahili_coastal` waterfront, `beach_banda`; see `region-dar-es-salaam.md` |
| Türkiye, Balkans, Levant | `fenn_rowhouse` (warm palette), `cycladic` coast | `modernist` | mosques `ottoman`; churches `byzantine` |
| Iran, Central Asia | `fenn_house` (sand palette) | `modernist` | mosques `persian` |
| South Asia | `fenn_rowhouse` (vivid palette) | `modernist` | mosques `mughal` |
| Russia, Eastern Europe | `fenn_rowhouse` | `fenn_office` | churches `orthodox` |
| Japan / China | `japanese` | `modernist` | `pagoda` (`japanese` / `chinese`) |

Heuristics when nothing is tagged: area < 250 m² and ≤ 3 levels → house family. Narrow
(< 8 m) street frontage with a deep plot → terrace family (`brownstone`, `dutch_canal`,
`fenn_rowhouse`). Over 40 m tall → tower presets. Over 60% glass in the material tags → `modernist`.

## 3. Style definition fields (`STYLES[name]`)

| Field | Meaning |
|---|---|
| `walls` | list of hex colours; picked by hash of the building id (or `spec.palette`) |
| `trim` | trims, parapets, boards, bands |
| `roof.kind` | `flat` (parapet sweep) · `hip` · `gable` · `mansard` · `curved_hip` (East Asian) |
| `roof.pitch`, `roof.overhang`, `roof.colors` | pitched roofs |
| `roof.gable_mode` | `short` (ridge along long axis) or `street` (gable faces the street: temples, canal houses) |
| `roof.parapet`, `roof.cornice`, `roof.cornice_color`, `roof.color` | flat roofs: profile names from `core.PROFILES` |
| `radius`, `segs` | corner rounding (0 for pitched-roof styles; large for streamline) |
| `floor_h`, `levels` | defaults when the spec has no height |
| `window`, `street_window`, `spacing`, `ground_windows` | module names (composites allowed: `window_tall+lintel`) |
| `door`, `door_pos` (`center` / `side`), `door_z` | entrance |
| `facade` | `punched` (instanced windows) or `bands` (glass + slab sweeps) |
| `plinth`, `bands` | base plinth sweep, per-floor band sweeps |
| `extras` | list of extra generators (section 4) |

## 4. Extras reference

| Extra | Does | Geometry vs instances |
|---|---|---|
| `bay` | trapezoid push-out on the street edge, before rounding | footprint |
| `portico` | podium, steps, columns, entablature; extends the roof footprint (pre-roof hook) | shell + `column` |
| `porch` | deck, slim posts, shed roof (single-plane `ConvexRoof`) | shell + `column_slim` |
| `turret` | round tower at the street corner, bands, windows facing out, flared cone + finial | shell + windows |
| `stoop` | stair module at the door (pair with `door_pos: side`, `door_z`) | `stoop` |
| `dormers` | dormer instances on the street roof slope at the roof height | `dormer` |
| `chimneys` | chimneys at the short-edge ridge ends, sunk into the roof | `chimney_brick` |
| `roof_props` | chimneys / AC boxes on flat roofs (deterministic) | `chimney` |
| `half_timber` | brick ground floor, timber posts avoiding windows, beams, braces | flat offset strips |
| `timber_frame_jp` | posts every 1.8 m, floor and eave beams | flat offset strips |
| `pilasters` | protruding vertical piers at edge ends (+ centre) | shell boxes |
| `stepped_parapet` | ziggurat panel centred on the street façade | `panel()` |
| `speed_bands` | three thin bands near the top, all round | sweeps |
| `mission_parapet` | curved gable panel + oculus | `panel()` + `window_round` |
| `arcade` | arch bays in front of the façade + terrace slab + end walls | `arch_bay` + shell |
| `stacked_cubes` | smaller cube on the roof with soft parapet, windows, door, optional blue dome | shell + modules |
| `dutch_gable` | crow-stepped gable panel + gable windows | `panel()` + windows |

Flat offset strips (`wall_strip`) cost 2 triangles each and sit 1–2 cm in front of the wall.
Keep glass at 3 cm so strips never z-fight with windows.

## 5. Adding a new style

1. **Write down 3–5 signature cues** from reference photos: the ones a person would name when
   recognising the style. Everything else is palette.
2. **Map each cue to an existing primitive** before writing code:
   - roof form → `roof.kind` / `pitch` / `gable_mode`
   - trims → a `PROFILES` sweep
   - openings → a module or a composite (`window_arched+balcony`)
   - façade figures (gables, parapets, pediments) → `panel()` with a 2D outline
   - surface pattern (timbering, bands) → `wall_strip`
   - protrusions → `edge_box`
3. Only if a cue has no primitive, add an extra `x_name(ctx)` that uses `ctx.street`, `ctx.edges`,
   `ctx.roof.z(p)`, `ctx.poly`, `ctx.H`, `ctx.floor_h` and appends to `ctx.b` / `ctx.inst`. Register it
   in `EXTRAS`, and in `GEOMETRY_ONLY` if it should survive at LOD1.
4. Add new window or ornament shapes as modules in `modules.py` (`BASES` + `SIZES`).
5. Render with `preview_render.py` from the street side and from 45° above. Compare silhouettes
   against the gallery. If the style doesn't read at 200 m distance, its signature cue is too small.
   Exaggerate it (thicker, higher contrast) rather than adding detail.

Example: a **Parisian Haussmann** style would be `walls` cream stone, `roof.kind: mansard`
(zinc grey), `window: window_tall+balcony` on floor 2 via `street_window`, `bands: true`, and
`cornice`. Zero new code.

## 6. Budgets per style (LOD0)

All styles stay within the SKILL.md building budget: under 1,500 unique triangles for
ordinary footprints. The heaviest are `art_deco` (bands + pilasters on rounded corners) and
`greek_revival` (portico). Instances dominate rendered triangles. Window modules are 34–85
triangles; balconies (~90) and columns (~140) are the expensive ones, so drop them to LOD1
first.
